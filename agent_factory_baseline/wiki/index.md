# Wiki анализа LLM-ассистентов и агентских систем

Версия набора фиксируется SHA-256 каждой страницы в knowledge.json конкретного прогона. Это рабочая методология команды, а не доказательство требований любого анализируемого проекта.

- [Границы домена](domains/llm-agents.md): информационные ассистенты, действия, RAG, ограниченные модели и внешние зависимости.
- [Основания и цена ошибок](methodology/evidence.md): источник, пересказ, вывод, неизвестное, приоритет.
- [Связи разделов](methodology/relations.md): процедура; конкретные правила — в relations.json рядом со страницей.
- [Формат паспорта](passport.md): назначение полей, состояния и источники истины.
- [Кейсы](cases/index.md): реестр, подтверждения и границы переносимости.

Инструкции отдельных цехов находятся в fields/: по одному файлу на field_id. YAML frontmatter этой страницы задаёт catalog_version и упорядоченный список fields. Frontmatter каждой страницы fields/<id>.md задаёт id, title, depends_on и checks (id, extract, evaluate); тело страницы раскрывает предметные процедуры. Это единый исходный каталог цехов. catalog.py содержит только загрузку и проверку формата. При планировании из снимка этих страниц создаётся catalog.md со всеми актуальными полями и checklist IDs.

## Устройство одной проверки

На странице цеха найди заголовок текущего check_id. «Относится, если» задаёт смысловую границу, «Не относится» — близкие исключения, «Извлечь» — конкретные атрибуты, «Если сведений не хватает» — работу с частичным основанием. Граничные примеры показывают различающий признак на самостоятельном входе. Не выбирай принадлежность по совпадению слов с примером и не требуй всех атрибутов для found. Достаточность для satisfied проверяется отдельно по evaluate и разделу заключения.

## Работа агента

Назначенные страницы автоматически включены через wiki_refs. Если нужен пример, уточнение критерия или правило смежного раздела, используй wiki_search и прочитай подходящую страницу через wiki_get. Сам факт нахождения похожего текста не даёт основания переносить условия кейса на проект.

## Изменения знаний

Методологию и страницы цехов редактируют в исходной wiki; следующий прогон создаёт новый снимок. Для собственной wiki передай --wiki-dir с полным набором страниц и реестров. Старые прогоны остаются воспроизводимыми по своему снимку; агент читает только его и не изменяет базу во время анализа.
